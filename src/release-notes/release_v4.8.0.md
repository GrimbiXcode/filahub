## Sign in with Discord

If this instance offers it, the sign-in page now has a **Sign in with Discord**
button next to Telegram. filahub only receives your Discord ID and username –
no email address, no servers, no messages.

## Connect Discord to your account

Already signed in with Telegram? Under **Settings → Sign-in methods** you can
connect your Discord account. After that, both ways lead to the same account
with all your stock. You can disconnect Discord there again at any time.

## Using the installed app

If Discord sends you back to your browser instead of the installed app, the
browser shows a **6-digit code**. Enter it in the app on the sign-in page under
**Enter code from the browser** – the code only works there and for five
minutes. Never give this code to anyone else.
