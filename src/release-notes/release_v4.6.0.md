## Bulk editing in the overview

You can now change several containers in one go – for example, enter the price
for a whole order at once instead of opening every spool.

- In the **list** view (and in the card list on your phone), tap **Select**.
  Check the containers you want, or tick the box in the table header to select
  everything currently shown.
- **Edit** opens one form for all of them: price, purchase date, nominal
  amount and drybox. Only the fields you check are changed – everything else
  stays as it is. Check a field and leave it empty to clear it.
- **Used up** marks all selected containers as used up in one step.

Only containers that are currently shown count: if you set a filter after
selecting, the hidden ones are left alone.
