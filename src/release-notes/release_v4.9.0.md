## Printers

The new **Printers** page lists your printers and which spool is currently
loaded in each of them. A printer can have several slots – one for a printer
with a single spool, five for an MMU3, four per AMS. Pick a container for each
slot, or unload it again with one tap. A container can only sit in one slot at
a time: loading it somewhere else takes it out of its old place.

Marking a container as used up or deleting it also takes it out of the
printer. The container page shows where a spool is currently loaded.

## Usage suggested from the loaded spools

When you log a print, filahub now suggests exactly the spools that are in the
printer:

- **From G-code and the inbox:** if the print names one of your printers,
  filament 1, 2, 3 … is matched to the container in slot 1, 2, 3 … – no more
  guessing by colour when four spools of the same material are loaded.
- **In the print form:** pick the printer and the loaded spools appear as
  buttons above the material rows. The material picker lists them at the top,
  too.
- **Log usage and weigh from the quick search:** loaded spools come first.

Use the same printer name as in your print history or slicer profile – that is
how filahub recognises the printer of a print.
