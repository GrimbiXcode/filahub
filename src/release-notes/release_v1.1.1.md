## No more sideways scrolling

On narrow screens, the date field in a dialog could grow wider than the dialog
itself and push the content off to the right, so the page slid sideways under
your finger. It now stays inside its column.

Dialogs that used to touch both screen edges — the catalogue editor and the
suggestion forms — have their margin back.
